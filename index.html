Structure

Five folders. That's the whole system.

Every note has one obvious home, so you and the agent always file things the same way.

_inbox/

Quick captures. Process within 7 days.

daily/

One note per day, YYYY-MM-DD.md. Append-only.

projects/

Active work only. Archive after 2 weeks untouched.

people/

One folder per regular contact. Used for 1:1 prep.

_archive/

Dormant material. Archive is not delete.

How it works

Plain files, clear rules, hooks that enforce them.

CLAUDE.md tells the agent where things go. Hooks make sure it sees those rules and records what it did.

Hooks

Guardrails at every step of a session.

Small scripts in .claude/hooks/ run at fixed points, so the rules don't fade during a long session.

Everyday use

Ask for the chores you keep putting off.

These workflows are built into CLAUDE.md. The agent proposes changes and waits for your approval.

Optional: a weekly review for your role

Example slash commands in .claude/commands/. Keep the ones that match how you work and delete the rest.

/weekly-review-pm

Product manager

Sprint changes, 1:1 prep for each direct report, and stakeholder updates.

/weekly-review-founder

Founder

Decisions, shipped work ready for an investor update, and open questions.

/weekly-review-freelancer

Freelancer

Hours and scope drift per client, matched to how each one is billed.

/weekly-review-kw

Knowledge worker

Meetings, decisions, and asks that have gone quiet, however old.

Setup

Up and running in four steps.

Requires bash, jq and python3. gh is optional.

Create your vault from the template

Keep it private, since it will hold your notes.

$ gh repo create my-vault --private --template shaynemeyer/vault-template --clone

No gh? Click Use this template on GitHub, or download the ZIP to keep the vault local.

Open it in Obsidian

Open the my-vault folder as a vault in Obsidian.

Make the rules yours

Edit CLAUDE.md to set the title and adjust the rules to taste.

Start your agent from the vault root

Run Claude Code or Kiro in the vault folder. It should report "Vault context loaded".
